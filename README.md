# Job Listings with Filtering

A responsive job board web application where users can filter positions by role, category, and experience level. Built with React, Material UI, and Vite, with all job data loaded locally from a JSON file. Deployed to Netlify.

## Features

* **Interactive Job Filtering**
  Filter job listings dynamically based on multiple selected categories such as role, level, tools, and languages.

* **Local JSON Data**
  Job data is sourced from a local `data.json` file and rendered dynamically with React.

* **Responsive Layout**
  Optimized UI that adapts to various screen sizes for a smooth browsing experience on mobile, tablet, and desktop.

* **Accessible Interactions**
  Includes hover and focus states for all interactive elements, improving usability and accessibility.

* **Modern UI Design**
  Styled with Material UI for clean, consistent components and intuitive user interactions.

## Built With

* **React** – Component-based UI development.
* **Material UI** – Modern, accessible UI components.
* **Vite** – Fast development tooling and bundling.
* **Netlify** – Hosting and continuous deployment.

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/npkorintus/filterable-job-listings.git
   ```

2. Navigate into the project directory:

   ```bash
   cd filterable-job-listings
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open your browser and visit the local URL printed in the terminal (typically `http://localhost:5173`).

## Usage

* Filter job listings by clicking category tags on any job card.
* Remove filters individually or clear all filters at once.
* Browse comfortably across devices thanks to the responsive layout.
* Experience smooth interactions with Material UI’s built-in styling, states, and transitions.
